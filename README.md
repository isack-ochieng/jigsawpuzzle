# Jigsaw Puzzle

A cross-platform Flutter jigsaw puzzle game for Android and iOS.

## Features

- Upload an image from the device photo library.
- Split the image into 9, 16, or 25 pieces.
- Drag pieces onto their matching board position.
- Restart the same puzzle or choose a different image.

## Run

Install the Flutter SDK, then run:

```sh
flutter pub get
flutter run
```

On Android or iOS, grant photo-library permission when prompted.
